# policy-verification · 政策官方核验

## 核验目标

确认政策变化是否由外国政府或国际组织正式发布,并核对动作、适用范围、发布日期、生效日期和政策状态。

## 官方优先级

1. 政府公报、农业/检疫/海关机构正式公告;
2. WTO ePing SPS 通报原文(含 G/SPS/N 编号);
3. 国际组织正式决定或成员官方声明;
4. 官方通讯社/权威行业媒体(只能作为线索,必须回溯原文)。

## 结论

- `verified`:找到至少一个官方原文,关键字段一致;
- `single_source`:暂时只有一个有效来源,即使是官方源也如实标记;
- `unverified`:检索后没有找到独立官方出处;
- `false_positive`:官方原文与线索在政策动作、国家、日期或状态上存在实质矛盾。

## 必查字段

- 动作:收紧 / 放松 / 调整 / 恢复;
- 状态:草案 / 已发布未生效 / 已生效 / 已解除 / 不明;
- 影响范围:国家/地区、商品、病害、企业、口岸;
- 法律依据/公告文号和生效日期;
- 原文 URL、发布日期、关键引用。

## 红线

- 找不到官方源不等于假消息,只能保持 `unverified`;
- 不把媒体的"拟将"改写成已生效政策;
- 解除/恢复类政策与收紧类同等重要,都要记录;
- 中国海关总署公告不进入本政策采集台账。
